    How it works

    ▶

    Start Focus in One Click

    Click Play (▶) to send the task name and project straight into the focus timer. Less setup, less context switching.

    ⏳

    Pomodoro-Style Countdown Presets

    Use the Countdown button to start a preset session (for example 25 minutes). Perfect for Pomodoro, time-boxing, and study sprints.

    🖱️

    Drag & Drop Priorities

    Your plan changes—your list should too. Drag and drop any item to reorder your task queue instantly.

    🏷️

    Projects & Smart Tags

    Assign tasks to projects for a cleaner task list. Tags match your project colors automatically so your queue stays readable.

    ✍️

    Edit Fast, Keep Momentum

    Double-click a task to edit it in place. Small friction removed = more deep work.

    ✅

    Finish, Clear, Repeat

    Mark tasks done as you go, then use Clear Done to sweep finished items. Keep today’s queue short and focused.
